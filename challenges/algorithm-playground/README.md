# Algorithm Playground

This neutral maintained demo consolidates three algorithm-focused historical
projects:

- Conaz supplies character frequency, run-length encoding, and monthly member
  synchronisation exercises.
- PropertiaG supplies validated integer-to-Roman-numeral conversion.
- Devlandia supplies full-path and next-move solutions for the Ruby “Bot saves
  princess” exercise.

The dependency-free Astro and TypeScript implementation presents every
exercise in an accessible tabbed workspace. The immutable sources remain in
`../challenge-conaz/original/`, `../challenge-propertiag/original/`, and
`../challenge-devlandia/original/`.

The canonical route is `algorithm-playground`. The six former source and
capability slugs remain available as redirects.
