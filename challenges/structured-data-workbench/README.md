# Structured Data Workbench

This maintained React demo consolidates three rule-driven data challenges into
one workspace:

- Salsify contributes its original product datastore, dynamic property and
  operator controls, value selection, filtering behavior, and result table.
- Stormtech and Zygo contribute their equivalent four-book fixtures, ordered
  comparison rules, documented presets, and explicit null and empty outcomes.

Product filtering and book sorting remain distinct workspaces beneath shared
navigation. All records are deterministic and local, and the historical
Express and MongoDB services are not contacted. The immutable sources remain
under their three original challenge directories.

The canonical route is `structured-data-workbench`. The former
`product-data-table` and `configurable-book-sorting` routes, together with all
three historical source slugs, remain available as redirects.
