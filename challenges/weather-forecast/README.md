# Weather Forecast Explorer

This maintained portfolio demo consolidates the overlapping Blueticket and
OnSign TV weather challenges. Their immutable historical sources remain in
`challenges/challenge-blueticket/original/` and
`challenges/challenge-onsign-tv/original/`.

The Vue 3 adaptation combines address search, private browser geolocation,
recent-search suggestions, a six-hour comparison, and a detailed 48-hour local
forecast. It uses deterministic fixtures and never contacts the historical
Google Maps or OpenWeather services.
